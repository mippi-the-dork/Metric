## 0.10.0 update for existing starter assets

Add the new **Camera Sightline** group using the values above. It defaults **Off** for both starter presets so upgrading Metric does not add another viewport layer until you choose to test it.

When enabled, Human uses a 140 cm subject point with a 25 degree framing half-angle and 4 cm occlusion sweep radius. Heavy uses a 240 cm subject point, tighter 22 degree framing half-angle, and 6 cm sweep radius. Camera Sightline evaluates from the resolved Camera Probe position whenever Camera Probe is active.

Existing project assets remain untouched until you apply these values manually. Fresh starter assets created by 0.10.0 receive these values automatically.

These values are spatial reference defaults, not claims about any project's actual camera implementation. Native Unreal Preview Mesh entries remain visual-only.


## 0.11.0 update for existing starter assets

There are **no new `UMetricPreset` Data Asset fields in 0.11.0**. `DA_Metric_Human` and `DA_Metric_Heavy` keep all 0.10.0 values exactly as listed above.

Pinned Benchmarks are session-level Metric viewport state, not preset data, so no Human or Heavy asset edits are required for this pass.


## 0.12.0 update for existing starter assets

There are **no new `UMetricPreset` Data Asset fields in 0.12.0**. `DA_Metric_Human` and `DA_Metric_Heavy` keep all 0.11.0 values exactly as listed above.

Persistent Pinned Benchmarks are editor-user state, not preset data. No Human or Heavy Data Asset edits are required for this pass.


## 0.13.0 update for existing starter assets

Add the new **Sensor Field** group using the values above. It defaults **Off** for both starter presets so upgrading Metric does not add another large viewport layer until you choose to enable it.

Human uses a 1800 cm range, 90 degree horizontal field, 60 degree vertical field, and 9 horizontal obstruction samples. Heavy uses a 2200 cm range, 80 degree horizontal field, 50 degree vertical field, and 11 horizontal obstruction samples. Both use the preset's existing Primary Sensor Height as the field origin and Visibility as the default trace channel.

The field is a spatial approximation. Its clear percentage comes from the horizontal ray fan only and does not reproduce AI Perception or project-specific sensing logic. Existing project assets remain untouched until you apply these values manually. Fresh starter assets created by 0.13.0 receive them automatically.
